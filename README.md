# MyVetClinic

Professional veterinary clinic website built with React + SCSS + Vite.

## 🐾 About

A modern, responsive veterinary clinic website featuring:
- Sticky navigation with mobile hamburger menu
- Full-viewport hero section with animations
- Services, Team, Pricing, Gallery sections
- Client testimonials
- Contact form with validation
- Smooth scroll and fade-in animations

## 🚀 Setup

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## 🛠 Tech Stack

- **React** + **Vite**
- **SCSS** with partials and mixins
- **Google Fonts** (Poppins, Inter)
- **Intersection Observer** for scroll animations
